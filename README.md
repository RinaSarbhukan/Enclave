# Enclave

Enclave is a browser-based CSV analysis tool. Upload a CSV, TSV, or TXT file to explore data, review statistics, generate charts, filter records, clean data, and export results. Files are processed locally in your browser.

## Run

Requires Node.js. From the project directory:

```bash
npm install
npm start
```

Open the local URL printed by the server.

## Tests

```bash
npm test
```
